# Nequix dataset versions

Each subdirectory here is one immutable snapshot of the Nequix PFT training
database, generated by `scripts/convert_to_nequix.py`. Never overwrite or
regenerate into an existing version directory — create a new one instead so
older datasets stay available for comparison/rollback.

Each version directory contains:

- `dataset.aselmdb` — the ASE database (gitignored, large binary)
- `materials.txt` — manifest of every material name included, auto-written
  by the conversion script

## Versions

| Version | Materials | Source | Notes |
|---|---|---|---|
| `v1_46materials` | 46 | `FINAL_RESULTS_HEALTHY` | Bilayer batches 1-3 complete; original curated set |

## Creating a new version

```bash
python3 scripts/convert_to_nequix.py \
    --source FINAL_RESULTS_HEALTHY \
    --output nequix_datasets/vN_<material-count>materials/dataset.aselmdb
```

Then add a row to the table above describing what changed (materials added,
source directory, why). Pick `--source` to match the desired set
(`FINAL_RESULTS` for everything, `FINAL_RESULTS_HEALTHY` for the curated
subset — every dataset packaged here is already the healthy/curated set, so
there's no need to spell that out in the folder name), and use
`--monolayer`/`--bilayer` to restrict further if needed. Name folders
`vN_<count>materials` — no dates; the version table above is where history
lives.
